# blog-template

読者にとって価値のある日本語のブログ記事を、AI エージェント（Claude Code）と一緒に書くためのノウハウとテンプレートです。特に、**AI が書いた文を自然な日本語にする方法** に力を入れています。

ノウハウの元は、次の 3 つです。

- 記事「[AWS試験を初めて英語で受けて分かったこと](https://qiita.com/kenken38/items/bd9ac1951e42b4fb8aa7)」を書くときに、著者がエージェントに出した指示
- エージェントの下書きと、著者が手で直した公開版の差分
- 発表資料のテンプレート [slide-template](https://github.com/Kenta-Matsuda/slide-template) で積み重ねた教訓

## 最初に読むもの

| ファイル | 内容 |
|---|---|
| [natural-japanese](.claude/skills/natural-japanese/SKILL.md) | 自然な日本語にする手順。実際の前後の例を載せています。このリポジトリの中心です |
| [blog-craft](.claude/skills/blog-craft/SKILL.md) | 読者の決め方、著者に聞くこと、構成、事実の確かめ方、Qiita の記法、投稿前の点検 |
| [LESSONS.md](LESSONS.md) | 指摘と手直しの記録。根拠が著者の発言か、差分からの推測かを書き分けています |
| [CLAUDE.md](CLAUDE.md) | エージェントが毎回読むルールの要約 |

## 一番大事なこと

AI 臭さには 2 種類あります。

1. **飾りすぎ**：比喩、決め台詞、絵文字、枠、太字が多い文
2. **硬すぎ**：飾りを消した結果、説明書のような文が同じ調子で続く文

1 だけを直すと 2 になります。著者の手直しを見ると、2 を直しているのは次の 4 つでした。

| 直したもの | 下書き | 公開版 |
|---|---|---|
| 省略を補う | 理由は2つあります。 | 英語受験した理由は2つあります。 |
| 具体的な事実にする | 参加する前に | ラスベガスに行く前に |
| 文をつなぐ | 今回は、最後の問題を… | ですが今回は、最後の問題を… |
| 著者の感情を入れる | 残り時間は1分だった | 残り時間はまさかの1分 |

最後の感情は、AI が作るものではありません。エージェントは著者に尋ね、著者の言葉を使います。

## 使い方

1. GitHub の「Use this template」でリポジトリを作るか、このリポジトリを clone します。
2. `templates/article.md` をコピーして記事を書きます。記事はリポジトリの中のどこに置いても構いません。
3. Claude Code でエージェントに依頼します。エージェントは `CLAUDE.md` を読み、必要なスキルを使います。
4. 記事を確かめます。

   ```bash
   npm run check -- 記事.md
   ```

   Node.js だけで動きます。追加のパッケージは要りません。警告は、見直す箇所の候補です。著者が選んだ表現なら残して構いません。
5. 著者が手で直して投稿した後に、エージェントに `/retro 記事のURL` と伝えます。エージェントが公開版との差分を読み、教訓を `LESSONS.md` に残します。

## スキル

| スキル | 使うとき |
|---|---|
| `natural-japanese` | 日本語を書く、直すとき |
| `blog-craft` | 記事を企画、執筆、点検するとき |
| `/lesson` | 著者の指摘を教訓として記録するとき |
| `/retro` | 投稿後に、公開版との差分から学ぶとき |

## slide-template との違い

slide-template の教訓のうち、読み物にも当てはまるものを引き継ぎました。スライド向けのルールのうち、次のものはブログでは変えています。

| slide-template のルール | ブログでの扱い | 理由 |
|---|---|---|
| 括弧書きを使わない | 著者の本音や補足には使ってよい | 公開版に（自戒）（おこがましいですが）がある |
| 書き言葉だけにする | です・ます調を基本にし、軽い話し言葉を残してよい | 公開版に「なので」「わりと」がある |
| 比喩を使わない | エージェントの比喩は消すが、著者が選んだ語は残す | 著者が「縛りプレイ」を残すよう指示した |
| 文字を最小にする | 引き継がない | 読み物では文章で説明する |
