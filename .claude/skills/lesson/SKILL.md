# 指摘を教訓として記録する

著者の指摘を、次の記事で同じことを言われないための教訓にする。記事を直した後で行う。

## 手順

1. **指摘を特定する**：引数があればそれを、なければ直前の著者の発言を対象にする。著者の言葉をそのまま短く引用する。
2. **残すかを決める**：次のどちらかに当たるものだけ残す。当たらなければ「この記事だけの好みなので記録しません」と伝えて終わる。
   - 他の題材の記事でも起こる（書き方、日本語、構成、進め方）
   - エージェントの進め方の誤りで、また繰り返しそう
3. **重複を確かめる**：`LESSONS.md` に同じ趣旨の教訓があれば、その項目の「指摘」に今回の分と回数を追記する。2 回目になったら、`CLAUDE.md` に格上げする。
4. **書き足す**：`LESSONS.md` の末尾に、次の形で 1 件足す。ID は最後の番号 + 1 にする。
   ```markdown
   ### L0NN 〈ルールを短い 1 文で〉
   - 日付・記事：YYYY-MM-DD ・ 〈記事の題〉
   - 根拠の種類：発言 / 差分 / 自己点検
   - 指摘：〈著者の言葉の引用か、直した事実〉
   - ルール：〈次から何をどうするか。具体的に〉
   - 反映先：未反映
   ```
5. **反映する**（できるものだけ）
   - 日本語の直し方なら、`natural-japanese` の該当する節に、実際の前後の例を足す。
   - 進め方や構成なら、`blog-craft` の該当する節に 1 行足す。
   - 正規表現で見つけられるなら、`rules/check-rules.json` に足し、`npm run check` で誤検出を確かめる。
6. **報告する**：記録した ID とルールを 1〜2 行で伝える。
