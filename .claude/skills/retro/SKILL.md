# 投稿後の振り返り

著者の公開版は、自然な日本語の最も良い教材である。下書きとの差分から学び、このテンプレートに持ち帰る。

## 手順

1. **公開版を取得する**：Qiita の記事なら、URL の末尾に `.md` を付けると Markdown を取得できる。
   ```bash
   curl -sSL "https://qiita.com/ユーザー/items/ID.md" -o published.md
   ```
2. **文単位で差分を読む**：
   ```bash
   git diff --no-index --word-diff=plain 下書き.md published.md
   ```
   直したことを次の観点で分類する：省略の補足、具体化、接続詞、文の統合、語尾、感情、削除、事実の修正、構成。
3. **会話の指摘を洗い出す**：著者から受けた指摘を時系列で並べ、`LESSONS.md` と突き合わせる。
4. **根拠を書き分ける**：著者の言葉は「発言」、差分から読み取ったものは「差分」と書く。差分の理由は推測なので、断定しない。確かめたい推測は著者に聞く。
5. **反映する**：
   - 日本語の直しは、実際の前後の例を添えて `natural-japanese` に足す。
   - 新しい例でルールが変わるなら、古いルールを書き直す。例が多いだけのものは、代表的な例を残す。
   - 機械で見つけられる表現は `rules/check-rules.json` に足す。
6. **チェックを試す**：下書きと公開版の両方に `node tools/check.cjs` をかける。下書きの問題を見つけられること、公開版で著者が選んだ表現を error にしないことを確かめる。著者が選んだ表現が warn に出るなら、残してよい理由を確かめる。
7. **持ち帰る**：記事の本文は入れず、教訓とルールだけをコミットする。ブランチを切って PR を出す前に、著者に確かめる。
8. **報告する**：足した教訓の ID、変えたルール、著者に確かめたい推測を伝える。
